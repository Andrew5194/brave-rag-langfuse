## What I'm building

A portfolio-quality demo that showcases the value of the **Brave Search API** for building RAG pipelines, specifically the **LLM Context endpoint**. Audience is personal exploration / portfolio (recruiters, blog readers, technical hiring managers).

The demo makes **two comparisons simultaneously**:

1. **Quality** — baseline LLM (no retrieval) vs. Brave-grounded LLM → shows hallucination reduction
2. **Infrastructure** — Brave-grounded LLM vs. DIY RAG (manual pipeline) → shows how much engineering effort Brave's endpoint replaces

Use case slant: **current-events finance Q&A with citations** (cited-QA pattern, like Perplexity).

Evaluation framework: **LangFuse** (Cloud free tier). Three evaluators score every output:
- `citation_rate` (0–1, LLM-as-judge)
- `factuality` (1–5, LLM-as-judge)
- `latency_ms` (measured)

## Key design decisions made

- **5 hand-picked questions** in the eval dataset (central bank, earnings, macro data, M&A, refusal test). Small enough to live-demo in <60 seconds.
- **Three pipelines** with the same input/output contract:
  - `baseline` — LLM only, no retrieval
  - `grounded` — Brave LLM Context endpoint + citation-forcing prompt (~110 lines)
  - `diy_rag` — Manual RAG: Brave Web Search + trafilatura + chunker + sentence-transformers + FAISS + retrieval (~280 lines)
- **Same citation contract** across grounded and DIY (DIY imports `GROUNDED_SYSTEM` from `pipelines/grounded.py`)
- **Primary demo surface is a Jupyter notebook** (`walkthrough.ipynb`) with interleaved markdown narration + code cells + outputs. Live-runnable in ~2 minutes.
- **Package manager: `uv`** (not pip/venv). Uses `pyproject.toml` + `.python-version`.
- **No CLI scripts** — earlier iterations had `compare.py main()`, `demo.py`, `setup_dataset.py`; all deleted in favor of the notebook being the single source of truth.

## Key parameters and conventions

- `RUN_TAG` — bump between rerun attempts (`v1`, `v2`, etc.) so each variant gets its own LangFuse run column
- `ANSWER_MODEL` / `JUDGE_MODEL` env vars default to `claude-opus-4-5`
- Brave LLM Context endpoint: `context_threshold_mode="strict"`, `count=10`, `freshness="pm"` (past month)
- DIY pipeline: `count=10` for search, `k=8` for retrieval, paragraph-aware chunker with 500/50 size/overlap, `all-MiniLM-L6-v2` embedder, FAISS `IndexFlatIP`
- LangFuse experiments use `max_concurrency=5` for baseline/grounded, `max_concurrency=3` for DIY (local embedder + concurrent fetches benefit from less contention)
